# 怪獣体内治療作戦

## 作品概要

「Adventure in vivo」をベースに、ゲームシステムや演出を追加して発展させた作品です。

巨大な生物の体内を舞台に、プレイヤーが病原体と戦いながら治療を進めていく2Dシューティングゲームです。

## 開発環境

* Unity
* C#

## 追加・実装した内容

* オープニング会話システム
* 1文字ずつ表示する会話演出
* ステージ選択
* 体内の部位を選択するステージ構成
* プレイヤーのライフゲージ
* ゲーム進行を管理する処理
* オブジェクト間のイベント連携

## 制作について

「Adventure in vivo」で制作したゲームをベースに、ゲームとしての完成度を高めるための機能追加に取り組みました。

特に、複数のゲームオブジェクトやシステム間の処理をイベントによって連携させるなど、処理同士の依存を抑えながらゲームを構成することを意識しています。
